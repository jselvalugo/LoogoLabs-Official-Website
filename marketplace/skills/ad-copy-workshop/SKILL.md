# Ad Copy Workshop

Turn a product, an offer and an audience into ready-to-paste ad copy, written in several distinct angles and checked against each platform's limits.

## 1. Gather the inputs

Before writing, make sure you have the following. Ask for anything missing in one short message; do not guess the offer.

- **Product**: what it is, in one sentence.
- **Audience**: who it is for and the problem they feel.
- **Offer**: what the click gets them (trial, demo, discount, lead magnet).
- **Platforms**: which of Meta, Google Search, LinkedIn, TikTok.
- **Proof** (optional): numbers, reviews, logos, guarantees the user can stand behind.
- **Voice** (optional): words to use or avoid.

Never invent statistics, reviews or claims. If no proof was given, write angles that do not depend on it.

## 2. Pick angles

Write at least three angles that differ in *why someone would click*, not just in wording:

| Angle | The click reason |
|---|---|
| Pain | "This problem is costing you." |
| Outcome | "Here is the after picture." |
| Proof | "People like you already got this result." |
| Objection | "The thing stopping you isn't true." |
| Curiosity | "There's a better way you haven't seen." |

Name the angle above each set of copy.

## 3. Write to the platform's limits

| Platform | Field | Limit (characters) |
|---|---|---|
| Meta | Primary text | ~125 shown before "See more" |
| Meta | Headline | 40 |
| Meta | Description | 30 |
| Google RSA | Headline (write 15) | 30 each |
| Google RSA | Description (write 4) | 90 each |
| LinkedIn | Intro text | ~150 shown before truncation |
| LinkedIn | Headline | 70 |
| TikTok | Ad text | 100 |

Count characters for every line and show the count in brackets, e.g. `Stop guessing your CAC [21]`. Rewrite any line over the limit; do not just flag it.

For Google RSA, make headlines work in any combination: no headline should depend on another, and include the keyword in at least three.

## 4. Output format

For each platform, then each angle:

```
### Meta — Angle: Pain
Primary text [118]: ...
Headline [34]: ...
Description [27]: ...
CTA button: Learn more
```

Finish with a short **Testing plan**: which two angles to test first and the single metric that decides the winner (usually cost per result, not CTR).

## Rules

- Lead with the reader, not the brand.
- One idea per ad.
- Specific beats clever: "Book 3 more calls a week" beats "Supercharge your pipeline".
- Avoid words platforms often reject: personal attributes ("Are you overweight?"), guaranteed outcomes, all-caps.

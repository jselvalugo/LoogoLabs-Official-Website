# SaaS Email Sequences

Write lifecycle emails that move a user one step at a time toward the moment the product proves its value.

## 1. Gather

- Product and the **activation moment** — the action that makes users stick (e.g. "connected their first data source", "sent their first invoice").
- Sequence type: **Onboarding**, **Trial → paid**, or **Win-back**.
- Trial length or plan details, if relevant.
- Sender (a person's name usually beats the brand) and voice.
- What the user already sends, so you don't duplicate it.

Ask for the activation moment if it isn't given — the whole sequence is built around it.

## 2. Default structures

**Onboarding (5 emails, 10 days)**
| # | Send | Job |
|---|---|---|
| 1 | Immediately | Welcome + the one first step |
| 2 | Day 1 | Remove the most common blocker to that step |
| 3 | Day 3 | Show the outcome (customer example or use case) |
| 4 | Day 6 | Second feature that deepens value |
| 5 | Day 10 | Check-in, invite a reply |

**Trial → paid (14-day trial, 5 emails)**: Day 0 start · Day 3 quick win · Day 7 mid-trial value recap · Day 12 what you'll lose · Day 14 last day.

**Win-back (3 emails, 3 weeks)**: what's new · the honest ask ("what didn't work?") · last offer or graceful goodbye.

Skip or shorten emails when a user completes the activation moment — note the suppression rule for each email.

## 3. Each email

```
Email 2 — Day 1 — "Remove the blocker"
Send if: has not completed [activation moment]
Subject: ... (under 45 characters)
Preview: ... (under 90 characters, adds to the subject — doesn't repeat it)

Body (under 150 words)

CTA: [one button, verb-first]
P.S. (optional)
```

## Rules

- One email, one job, one CTA.
- Write like a person: short paragraphs, "you" more than "we".
- Subject lines say what's inside; no fake "Re:" or "Fwd:".
- Don't invent customer names, stats or quotes — leave `[customer example]` placeholders for the user to fill.
- End with a short table of all emails (send time, subject, CTA, suppression rule) so it can be built in any ESP.
